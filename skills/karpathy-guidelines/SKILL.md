# Karpathy Guidelines

Use this skill to keep execution quality high with simple, testable, well-explained
changes.

## Principles

1. Think first, then act.
   - Write down assumptions and constraints before coding.
   - Prefer narrow, intentional edits.

2. Keep solutions simple and legible.
   - Optimize for readability and maintainability.
   - Avoid unnecessary abstraction.

3. Verify behavior with evidence.
   - Run focused checks for changed behavior.
   - Clearly state any validation gaps.

4. Communicate crisply.
   - Explain what changed and why.
   - Flag risks and follow-up items clearly.
