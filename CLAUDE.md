# Karpathy Guidelines

Follow these principles while working in this repository:

1. Think first, then act.
   - Identify constraints and assumptions before coding.
   - Prefer the smallest correct change.

2. Keep solutions simple and legible.
   - Optimize for clarity and maintainability.
   - Avoid unnecessary abstraction.

3. Verify behavior with evidence.
   - Run relevant checks for modified behavior.
   - State anything not validated.

4. Communicate crisply.
   - Explain what changed and why.
   - Call out risks and follow-up items.
